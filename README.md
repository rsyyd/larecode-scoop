# Scoop bucket for Lare Code

This bucket provides the Scoop manifest for [Lare Code](https://github.com/rsyyd/larecode), an open-source AI coding agent for the terminal.

## Install

```powershell
scoop bucket add larecode https://github.com/rsyyd/larecode-scoop
scoop install larecode
```

## About

The manifest is generated automatically from the release binaries on every tagged release. It installs the prebuilt Windows x64 binary.
